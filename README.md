# 龍領主 Online 🐉

多人連線網頁 RPG — 三職業、四大地圖、裝備強化、二手市集、玩家交易、PvP、BOSS 討伐。

## 快速開始（本機執行）

**Windows 最簡單：** 安裝 [Node.js](https://nodejs.org)（LTS）後，直接雙擊 `start-game.bat` 即可！

手動方式：

1. 安裝 [Node.js](https://nodejs.org)（LTS 版本即可）
2. 在專案資料夾打開終端機，執行：

```bash
npm install
npm start
```

3. 打開瀏覽器，前往 `http://localhost:3000` 就能玩了！
4. 同一個 Wi-Fi 下的朋友可以用「你的區域網 IP:3000」加入
   （查 IP：Windows 用 `ipconfig`，Mac 用 `ifconfig`）

> ⚠ **Windows PowerShell 出現「因為這個系統上已停用指令碼執行…SecurityError」？**
> 這是 PowerShell 的執行原則擋住 npm，改用 `npm.cmd install` 與 `npm.cmd start` 即可；
> 或執行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`（按 Y）永久解決；
> 或干脆雙擊 `start-game.bat`，完全不用打指令。

## 部署到雲端（免費）

目前採用三方拆分架構：

| 服務 | 負責 | 上傳哪些檔案 |
|---|---|---|
| **Cloudflare** | 遊戲畫面（免費、流量無上限） | `public/` 整個資料夾 |
| **Render** | WebSocket 連線與遊戲邏輯 | `server.js` ＋ `public/shared/gamedata.js` |
| **Supabase** | 玩家存檔資料庫 | 不用上傳，設 `DATABASE_URL` 即可 |

Render 設定：Build Command 填 `npm install`，Start Command 填 `npm start`。
Cloudflare 設定：`wrangler.jsonc` 的 `assets.directory` 指向 `./public`。

> ⚠ **兩個重點**
> 1. `public/shared/gamedata.js` 是**伺服器與瀏覽器共用**的設定檔（地形迷宮靠它兩邊各自算出相同結果）。
>    它必須放在 `public` 裡面，Cloudflare 才載得到；而且**兩邊版本一定要一致**，
>    否則會發生「看得到路卻走不過去」「商店標價和實際扣款不同」。
> 2. 換伺服器網址只要改 `public/client.js` 最上面的 `SERVER_URL` 一行。
>    本機測試（localhost / 區網 IP）會自動連本機，不必改。

**發佈新版前先執行一次：**

```bash
node stamp-build.js
```

它會把版本代碼寫進 `index.html`，讓玩家的瀏覽器抓到新檔案（靜態主機沒有伺服器可以即時改寫，
所以要先寫死進去）。

## 操作

| 按鍵 | 功能 |
|---|---|
| W A S D / 方向鍵 | 移動（手機用左下角浮水方向鍵） |
| 滑鼠左鍵 / 空白鍵 | 普通攻擊 |
| Q / E | 職業技能（右下也有技能圈可點） |
| T | 一轉技能（一轉後才會出現） |
| R | 喝快速回血瓶 |
| B | 背包／裝備（紙娃娃） |
| F | 撿取／互動（商店・鐵匠鋪・旅店・二手商店・交易所・寶箱・傳送門） |
| Enter | 開啟全服聊天（手機點 💬 按鈕） |
| P | 線上玩家列表（手機點 👥 按鈕） |

右下角「自動」＝自動攻擊，**會自動繞路**找下一隻怪（不放技能）；
旁邊「**PK**」開啟後，自動攻擊也會鎖定玩家（城鎮內除外）——射手 PK 不再打不到人。
手機支援：**浮動虛擬搖桿**（手指按左半螢幕任意處即以該點為圓心，可 360 度類比移動）、
觸控技能圈、自動縮放視野、直式與橫式版面。背包點一下選取、再點一次即可裝備。

### 直式手機的商店介面（已針對單手操作重做）

- 所有面板（商店・裝備店・鐵匠鋪・背包・聊天・玩家列表）在手機上改為**底部抽屜**：
  滿版寬度、頂端圓角與拖曳提示條，**標題與 ✕ 永遠固定在上方**、確認按鈕固定在下方，中間才捲動
- 商品改為**兩行卡片**：上排 圖示＋名稱＋屬性＋價格，下排**整條全寬購買鍵**（高度 46px 以上，好按不誤觸）
- 每件商品都有**裝備圖示**，一眼看得出買的是什麼
- 面板頂端固定顯示**持有資源**（金幣・回血瓶・卷軸・箭矢），不用關掉商店去看
- **金幣不足的商品自動變灰**，不會按了才知道
- 回血瓶與強化卷軸可**一次買 10 個**（箭矢 ×100／×1000），不用連點
- 非射手職業**自動隱藏箭矢**，直式畫面少捲一大段
- 鐵匠鋪強化率改為**標籤排列**（藍框＝失敗不降級），不再被螢幕切掉
- 點面板外的**灰色區域即可關閉**

角色非戰鬥時會把武器收在背上／腰間，攻擊或受擊 4 秒內才拔出武器。

## 遊戲內容

- **等級上限 350**，每種小怪各 **40 隻**（原本 15 隻）
- **一轉系統**：等級到 350 後，在背包面板按「⭐ 一轉」即可轉生
  - 等級回到 **Lv.1**，但**裝備、金幣、道具全部保留**
  - 之後打怪**經驗值 150%**，等級旁會出現金色「**1轉**」標記（線上名單、角色頭上也看得到）
  - 解鎖各職業的**第三個技能**（快捷鍵 **T**，手機右下也會多一顆金框技能圈）：

| 職業 | 一轉技能 | 效果 | 冷卻 |
|---|---|---|---|
| 戰士 | ⚡ 震地斬 | 跳起把劍插進地面，1.5 個商店大小的範圍造成 **300%** 傷害、**50% 爆擊**，並把敵人擊退**半個商店**的距離 | 15 秒 |
| 射手 | ❄ 緩速箭 | 射出寒冰箭，**200%** 傷害、**30% 爆擊**、**不消耗箭矢**；命中者移動速度變 **0.4 倍持續 4 秒** | 15 秒 |
| 刺客 | 🌑 隱身突襲 | 隱身 **3 秒**（其他玩家看不到你、怪物不鎖定你，你仍看得到別人），移速 **+30%**；隱身後的第一次普攻造成 **370%** 傷害（攻擊或放技能會現形） | 15 秒 |

- **三職業**：戰士（近戰橫掃）、射手（遠程・消耗箭矢）、刺客（高速高爆擊）
- **職業技能**（Q/E）：戰士＝旋風斬/衝鋒、射手＝三連矢/爆裂箭、刺客＝影襲/毒刃
- **四張地圖**：碎裂之峰(1-50) → 黑暗聖殿(50-150) → 火山王座(150-350) → 中崙學園（王的領域）
  - 前三張地圖與城鎮**尺寸皆為 2 倍**（6800×4800）；中崙學園維持原尺寸
  - 主要地圖 1:4000 迷宮化地形；每張有城牆城鎮（西/東雙門、**六棟建築**：裝備店、雜貨商店、鐵匠鋪、住宿旅店、二手商店、交易所、莊嚴復活點、BOSS 出現大空間）
  - BOSS 位於離城鎮最遠的專屬領地（魔像深谷／黑暗聖所），脫戰 5 秒會快速回血
  - 進第二圖需擊敗小BOSS「岩石魔像」；進第三圖需擊敗「黑暗信徒」且達 150 級
  - **所有 BOSS 數值為原本的 1.4 倍**（小BOSS ×4.2、龍領主 ×7 倍同級怪）
  - 火山王座寶箱 5% 開出「火山鑰匙」（有保底），集齊 3 把可開啟中央古代火山傳送門
  - 第四圖以中崙高中平面圖為參考（1:500），龍領主 伊格尼斯坐鎮 707 班
  - 首殺 BOSS 獲得不可交易紀念道具（岩石核心／黑暗聖章）
- **裝備外觀**：六階級（新手／岩石／精鋼／黑暗／秘銀／龍神）各有專屬圖示，越高階越華麗
  （黑暗以上有雙角與寶石、秘銀會發光、龍神有龍鱗與火焰紋）；換裝後角色外觀即時改變
- **裝備品質**：灰 < 綠 < 藍 < 紫 < 金 < 紅 < 彩
  - **BOSS 掉寶品質固定**：岩石魔像＝**金裝**、黑暗信徒＝**紅裝**、龍領主＝**彩裝**（一次掉 2~4 件）
  - 寶箱只會開出灰／綠／藍
- **職業限制**：滑鼠移到裝備會顯示可否裝備，無法使用的武器在背包中以斜線與 🚫 標示
- **強化**：鐵匠鋪 +1(100%) 到 +10(0.5%)，每次消耗一張強化卷軸；
  **+4 以下失敗不會降級**（保護區），+5 起失敗才會掉一級
- **PvP**：擊殺 ±10 級玩家有 10% 掉裝；城鎮殺人會被 10 名士兵追殺 10 分鐘
- **經濟**：強化卷軸 30,000、回血瓶 1,000（回 1/5 血、CD 30 秒）、箭矢 1 金幣
- **背包擴充**：雜貨商店販售，每次 **+10 格**，價格 10 萬 → 20 萬 → 30 萬…依次遞增（最多 120 格）
- **旅店限制**：**攻擊別的玩家、或被玩家打到後 20 秒內不能住宿**，避免 PvP 中無限回血
- **鐵匠鋪回收**：不要的裝備可直接賣掉，價格依「階級 × 稀有度 × 武器加成 × 強化等級」計算
  （例：普通新手裝 120、金裝岩石武器約 8,100、彩裝龍神武器約 350 萬）
- **二手商店（全服寄賣）**：把裝備掛上去自訂售價，**全伺服器都看得到、都能用金幣買**；
  賣出後金幣自動入帳（**即使你不在線上**），伺服器重開也不會消失。
  **BOSS 掉落的裝備最低售價 150 萬金幣**，寶箱與商店裝備不限價；每人最多同時寄賣 8 件，可隨時下架
- **交易所（玩家面交）**：兩位玩家同時站在交易所 → 送出邀請 → 雙方各放入裝備與金幣 →
  **兩邊都按「確認」才成交**；任何一方改動內容都會清除雙方的確認（防掉包）
- **假人陪玩**：每一區都有一名 AI 假人在打怪，等級是該區的中間值（25 / 100 / 225 / 325）。
  它們會放技能、**被你主動攻擊就會反擊**、死後 1 分鐘復活、不升級也不掉裝，
  而且會像真玩家一樣出現在「線上玩家」名單（名字後面有 🤖）
- **全服聊天**：分成「💬 聊天區」與「🔔 系統通知」兩個分頁——玩家對話與升級、擊殺 BOSS、
  一轉、上下線等系統訊息不會互相洗版，各自有未讀數字提示；新上線可看到最近 25 則
- **線上玩家列表**：即時顯示全服玩家的角色 ID、等級、職業與所在地圖（依地圖分組、等級排序），
  上下線與等級變動 3 秒內自動更新；動作列的 👥 按鈕直接顯示目前線上人數

## 帳號與角色規則

- 每個帳號最多 **3 個角色**（建滿後選角畫面會自動隱藏建立區塊）
- **一個帳號同時只能有一個角色在線上**；在別的裝置登入同一帳號時，
  舊裝置會顯示提示並自動下線，舊角色立即從世界移除（不會留下幽靈角色）
- 遊戲中點右上角 **👤** 按鈕可存檔並回到選擇角色畫面
- 伺服器每 20 秒心跳偵測，手機切走或斷訊造成的殘留角色會自動清除

## 帳號資料與進度保存

預設進度存在 `data/db.json`（每 15 秒自動存檔）。
遊客模式依 IP 保存進度；註冊帳號可跨裝置遊玩。

### 讓雲端部署的進度永久保存（免費）

Render 免費方案每次重新部署會清空檔案，進度會消失。解法：接一個免費的雲端資料庫（Supabase）。

1. 到 [supabase.com](https://supabase.com) 註冊 → New project（Region 選 **Southeast Asia (Singapore)**），
   自己設一組 Database Password 並記下來
2. 專案建好後點上方「**Connect**」→ 選 **Session pooler** 那一段連線字串
   （⚠ 一定要用 Session pooler，Render 不支援 Direct connection 的 IPv6）
3. 把字串裡的 `[YOUR-PASSWORD]` 換成你剛設的密碼
4. 到 Render 你的服務 →「Environment」→「Add Environment Variable」：
   - Key 填 `DATABASE_URL`，Value 貼上完整字串 → Save（會自動重新部署）
5. Logs 出現「✔ 已連接雲端資料庫」就成功了——之後怎麼重新部署，進度都在！

> Supabase 免費方案：500 MB 資料庫（我們的存檔只有幾 MB）、閒置一週會自動暫停
> （**資料不會刪除**，到 Dashboard 按 Restore 約 30 秒即可復原；伺服器運作中會自動送 keep-alive）。
> 也可改用 Neon 等其他 Postgres，一樣只要換 `DATABASE_URL`，程式完全不用改。

## 更新遊戲後玩家看不到新版？

**發佈前一定要先跑 `node stamp-build.js`**，它會把新的版本代碼寫進 `index.html`，
玩家一重新整理就會抓到新檔案。登入畫面右下角會顯示 `build xxxxxxxx`，
可用來確認自己載入的是不是最新版（伺服器版本可打開 `你的 Render 網址/version` 查看）。

若前端是新版但行為怪怪的，通常是**只更新了 Cloudflare 沒更新 Render**（或反過來）——
兩邊的 `gamedata.js` 一定要同一份。

## 專案結構

```
server.js                 遊戲伺服器（帳號、世界模擬、戰鬥、掉落）→ Render
stamp-build.js            發佈新版前執行，寫入版本代碼破快取
public/index.html         遊戲頁面與 UI                          ↘
public/client.js          前端渲染與操作（最上面設定 SERVER_URL）   ├ Cloudflare
public/sprites/           角色與怪物圖片                          ↗
public/shared/gamedata.js 所有數值設定（伺服器與瀏覽器共用，兩邊都要同步！）
```
